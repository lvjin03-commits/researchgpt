# Grant Platform Architecture Decisions

Use an ADR when a change moves authority, modifies a core contract, introduces
a shared dependency, changes data sensitivity handling, or creates a temporary
compatibility path.

ADRs are immutable after acceptance. Superseding decisions create a new ADR and
link the previous record.

File naming:

```text
NNNN-short-decision-name.md
```

Use `0000-template.md` as the starting point.
