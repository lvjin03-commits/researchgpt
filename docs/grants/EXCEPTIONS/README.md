# Grant Platform Engineering Exceptions

An exception is an explicit, temporary deviation from the grant engineering
baseline. It is not permission to create permanent debt.

Create a dated file from `template.md`, obtain explicit approval, reference it
from the PR, and add the cleanup work to `docs/grants/TECH-DEBT.md`.

Exceptions require an expiry and rollback plan. The following are never
exemptible:

- current evidence authorization at model dispatch;
- user confirmation before formal AI writes;
- revision concurrency protection;
- durable audit linkage;
- non-fabrication of evidence, results, or references;
- protection of sensitive and unpublished material.
